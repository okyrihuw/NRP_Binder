# Выдача

Windows-программа для подготовки команд и удобной последовательной выдачи игрокам. Автор — Пепси Кольный, сервер — Байкальский, Discord — `okyrihuw`.

## Запуск и сборка

Для запуска исходников нужны Windows 10/11, Python 3.10+ и Tcl/Tk:

```bat
python main.py
```

Чтобы собрать автономный exe, запустите `build_exe.bat` на Windows. Результат появится в `dist\Выдача.exe`.

## ГМП

Четыре колонки — независимые группы игроков. В каждой можно указать до 15 ID, два скина и три значения оружия. Пустые поля пропускаются. Два заполненных скина делят ID пополам: первые получают первый скин, оставшиеся — второй; при нечётном числе первая половина на одного игрока больше. Один скин применяется ко всем ID группы. Оружие выдаётся каждому ID по порядку заполненных ячеек; используется 1000 патронов.

ХР и броня применяются ко всем заполненным ID. **Сохранить** записывает пресет, **Обновить из пресета** загружает последнее сохранение, **Очистить поля** не стирает сохранённый пресет.

Бинды: Ctrl+1 — телепорт к себе; Ctrl+2 — скины; Ctrl+3 — оружие; Ctrl+4 — здоровье; Ctrl+5 — броня; Ctrl+6 — возрождение.

## Полуавтоматическая очередь

Откройте F8 вручную, оставьте активным окно игры и нажмите бинд. Первая команда будет скопирована. Физически нажмите Ctrl+V, затем Enter; после нажатия Ctrl+V программа подготовит следующую команду. Повторяйте вставку и Enter до конца очереди — затем буфер очищается. Программа не открывает консоль и не нажимает Enter за пользователя.

Во вкладке **ИНФО** есть отдельные окна справки: «Как пользоваться ГМП» и «Режим работы программы».
