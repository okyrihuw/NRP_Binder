# Выдача — помощник для игровых команд

Небольшое Windows-приложение с интерфейсом по присланному образцу. Оно не встраивается в игру и не меняет её файлы: по включённым глобальным сочетаниям печатает заданные команды в активное окно игры через обычный ввод клавиатуры.

## Запуск из исходников

Требования: Windows 10/11, Python 3.10+ с установленным Tcl/Tk.

```bat
python main.py
```

## Сборка в EXE

Запустите `build_exe.bat` на Windows. Скрипт установит PyInstaller и создаст `dist\Выдача.exe`. Готовый EXE автономный; Python на целевом компьютере не нужен.

## Использование

1. Откройте вкладку **ГМП** и заполните ID игроков. Каждая из четырёх колонок — отдельная группа: скины и оружие из колонки применяются к ID в той же колонке.
2. Введите нужные значения. Пустое поле пропускается: пустые ID, скины, оружие, ХР или броня не превращаются в команды.
3. `sleep` — пауза между командами в миллисекундах. Если оставить пустым, используется минимальная пауза ввода.
4. **Сохранить** пишет пресет в `%APPDATA%\BindiVidacha\preset.json`; **Обновить** загружает его; **Очистить** чистит только поля на экране и не трогает сохранённый файл.
5. На вкладке **Команды** включите горячие клавиши, затем переключитесь в игру. Нажмите `Alt+Ctrl+1…6`, `Alt+Ctrl+8…0` для нужного действия. Комбинации и таблица действий соответствуют образцу.

При запуске действия приложение нажимает F8 один раз, вводит первую команду и нажимает Enter. Для следующих команд консоль не открывается повторно. Консоль остаётся открытой. Команда печатается в **активное окно**, поэтому перед нажатием горячей клавиши убедитесь, что активна игра и консоль готова принимать ввод. Если все соответствующие поля пусты, приложение ничего не отправляет.

Действия: телепорт к себе (`/get`), временные скины (`/tempskin`), выдача выбранных оружий (`/weapongive`, 1000 патронов на слот), здоровье (`/sethp`), броня (`/setarmor`) и возрождение (`/reviving`). Набор доступных серверных команд также открывается кнопкой **Список команд**.

Глобальные сочетания работают в Windows-сборке. Если сочетание занято другой программой, Windows не даст его зарегистрировать; отключите конфликтующую программу и попробуйте снова.
