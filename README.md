# Выдача

Windows-программа для подготовки и последовательной отправки игровых команд. Автор — Пепси Кольный; сервер — Байкальский; Discord — `okyrihuw`.

## Запуск и сборка

Для запуска исходников нужны Windows 10/11, Python 3.10+ и Tcl/Tk:

```bat
python main.py
```

Чтобы собрать автономный exe, запустите `build_exe.bat` на Windows. Результат: `dist\Выдача.exe`.

## Вкладка «ГМП»

- Четыре колонки — независимые группы игроков. В каждой до 15 ID, два поля скинов и три поля оружия.
- Если заданы оба скина, ID группы делятся пополам: первая половина получает первый скин, остальные — второй. При нечётном количестве первая половина получает на одного игрока больше. Один заполненный скин применяется ко всем ID группы.
- Оружие выдаётся по ID: сначала конкретному игроку все заполненные ячейки оружия по порядку, затем следующему. `/weapongive` получает 1000 патронов.
- ХР и броня применяются ко всем заполненным ID во всех группах. Пустые поля пропускаются.
- **Сохранить** записывает пресет в `%APPDATA%\BindiVidacha\preset.json`; **Обновить из пресета** загружает его; **Очистить поля** не удаляет сохранённый пресет.
- Справа включаются горячие клавиши и показаны действия: Ctrl+1 — телепорт к себе; Ctrl+2 — скины; Ctrl+3 — оружие; Ctrl+8 — здоровье; Ctrl+9 — броня; Ctrl+0 — возрождение.

## Полуавтоматическая очередь

Откройте игровую консоль F8 самостоятельно и оставьте активным окно игры. Включите горячие клавиши и нажмите бинд действия. Первая команда копируется в буфер. Вручную нажмите Ctrl+V, затем Enter. Программа замечает физический Ctrl+V и после короткой паузы кладёт в буфер следующую команду. Повторяйте Ctrl+V и Enter; после последней вставки буфер очищается. Программа не нажимает клавиши и Enter за пользователя.

Приложение проверяет совпадения биндов между включёнными категориями. Сейчас горячие клавиши есть только в ГМП; при добавлении новых категорий их наборы сочетаний подключаются к общей проверке.
