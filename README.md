# NRP Binder

Windows-приложение для подготовки игровых команд и последовательной работы с ними. Автор — Пепси Кольный, Discord — `okyrihuw`.

## Запуск и сборка

Для запуска исходников нужны Windows 10/11, Python 3.10+ и Tcl/Tk:

```bat
python main.py
```

Чтобы собрать автономный exe, запустите `build_exe.bat` на Windows. Результат появится в `dist\NRP Binder.exe`.

## Вкладка «МП»

Четыре независимые группы игроков: до 15 ID, два скина и три значения оружия в каждой. Пустые поля пропускаются. Два заполненных скина делят ID пополам; при нечётном числе первая половина на одного игрока больше. Один заполненный скин применяется ко всем ID группы. Оружие выдаётся каждому ID по порядку заполненных ячеек. ХР и броня применяются ко всем заполненным ID.

Бинды МП: Ctrl+1 — телепорт; Ctrl+2 — скины; Ctrl+3 — оружие; Ctrl+4 — здоровье; Ctrl+5 — броня; Ctrl+6 — возрождение.

## Вкладка «Forum»

Три колонки — «Мут», «КПЗ» и «Бан». В каждой строке укажите ID игрока, срок и причину. Полностью заполненные строки собираются в команды `/pmute ID СРОК ПРИЧИНА`, `/jail ID СРОК ПРИЧИНА` и `/pban ID СРОК ПРИЧИНА`; пустые и неполные строки пропускаются. Бинд очереди Forum — **Alt+Ctrl+1**.

У каждой вкладки свои кнопка очистки и переключатель биндов. «Сохранить» сохраняет введённые данные, «Обновить» загружает сохранённые данные. Очистка полей не удаляет сохранение. Если бинды включены сразу в нескольких вкладках, приложение проверяет конфликты сочетаний.

## Полуавтоматическая очередь

Откройте игровую консоль F8 вручную, оставьте активным окно игры и нажмите бинд нужной вкладки. Первая команда попадёт в буфер обмена. Физически нажмите Ctrl+V, затем Enter; после Ctrl+V программа подготовит следующую команду. Повторяйте вставку и Enter до конца очереди — затем буфер очищается. Программа не открывает консоль, не имитирует нажатия клавиш и не отправляет Enter.
