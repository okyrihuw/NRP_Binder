# Выдача — помощник для игровых команд

Windows-приложение для подготовки пресетов и последовательной выдачи игровых команд. Команды помещаются в системный буфер обмена по очереди: пользователь вручную вставляет каждую через `Ctrl+V` и отправляет клавишей Enter. Программа замечает физическое нажатие `Ctrl+V` и готовит следующую команду.

## Запуск и сборка

Требуются Windows 10/11 и Python 3.10+ с Tcl/Tk для запуска из исходников:

```bat
python main.py
```

Чтобы собрать автономный exe, запустите `build_exe.bat` на Windows. Результат: `dist\Выдача.exe`.

## Вкладка «ГМП»

- Четыре колонки — независимые группы игроков. В каждой можно задать до 15 ID, два значения скина и до трёх значений оружия.
- Если заполнены два скина, список ID группы делится пополам: первая половина получает первый скин, оставшиеся — второй. При нечётном числе ID первая половина получает на одного игрока больше. Если указан только один скин, он выдаётся всем ID группы.
- Оружие обрабатывается по ID: игроку выдаются все заполненные ячейки оружия по порядку, затем переход к следующему ID. Для команды `/weapongive` задано 1000 патронов.
- ХР и броня задаются отдельно и применяются к заполненным ID во всех четырёх группах.
- Пустые поля пропускаются. Пресет сохраняется в `%APPDATA%\BindiVidacha\preset.json`; очистка полей не удаляет сохранённый пресет.
- Горячие клавиши действий и их включение находятся здесь же. Перед запуском откройте в игре консоль F8 и убедитесь, что активным остаётся окно игры.

### Полуавтоматическая очередь

Нажмите бинд действия, например `Alt+Ctrl+1`: первая команда появится в буфере обмена. В игре вручную нажмите `Ctrl+V`, затем Enter. После физического `Ctrl+V` программа подготовит следующую команду; повторяйте вставку и Enter. После последней вставки буфер очищается. Нажатия Enter программа не имитирует. Очередь продвигается только при физическом `Ctrl+V` в том же окне, где был запущен бинд.

## Другие вкладки

- **ИНФО** — сведения о программе и авторе.
- **Команды** — справочник доступных серверных команд.
- **Тест** — три отдельных сочетания Ctrl+1/2/3, которые копируют тестовый текст в буфер обмена.
